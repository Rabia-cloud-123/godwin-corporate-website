# ASK Godwin Ltd — Homepage Preview

A responsive, premium corporate homepage built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. For the best development experience, use VS Code with the Live Server extension and choose **Open with Live Server**.

## Files
- `index.html` — page structure and homepage content
- `styles.css` — responsive styling and layout
- `script.js` — mobile navigation, scroll reveals, counters and testimonial preview interactions

## Before showing/launching to the client
- Replace the temporary brand mark with the approved ASK Godwin logo.
- Confirm the brand colours and typography.
- Replace placeholder email address and add approved phone/address/social links.
- Replace sample testimonial-style brand statements with approved real testimonials.
- Replace illustrative job/career and editorial content with verified content.
- Confirm all service descriptions, destinations, programme details and legal links with the client.
- Images are loaded from Unsplash and require an internet connection.

This is a frontend presentation prototype only. It does not include backend services, candidate/student portals, admin dashboard, registration, application submission, document storage or payment processing.
